# The redesign probe

This folder is the output of the July 26, 2026 redesign session. Nothing in it is served; the live site stays in `docs/` until each phase of the plan in `BRIEF.md` merges on its own pull request.

| File | What it is |
|---|---|
| `BRIEF.md` | The overhaul brief: purpose, diagnosis, the rebuild verdict, the new structure, the design system, the maintenance model, and the sequence. Read this first. |
| `site.css` | The design system as one stylesheet: tokens, the five-state status vocabulary, the serif-for-verbatim rule, the four page templates. |
| `index.html` | The front page rebuilt on the Dashboard template: status, the document-chain diagram, the next three dates, one open item. |
| `requirements.html` | The merged reference page: hours by role with the published-against-proposed chart, per-role tables with citations, one verbatim block showing the type treatment. |

Open the two HTML files in a browser from this folder. They are a probe of the design direction for the owner to react to, not the migration: navigation targets marked `#` are pages that do not exist yet, and the content, while drawn from the sources the site already cites, has not been through the verification pass that `docs/` pages get. Do not link to these files from `docs/`.

The chart palette (`#5B3FA8`, `#1D8A6F`, `#A5690E`) passes color-vision-deficiency and contrast validation against the paper ground.
